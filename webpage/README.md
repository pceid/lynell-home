# Lynell marketing webpage

Separat Vite/React/TypeScript-side for Lynell marketing. Denne appen ligger isolert under `webpage/` og er ikke koblet til Lynell Home runtime.

## Kjore lokalt

```bash
npm run dev
```

## Bygge

```bash
npm run build
```

## Preview

```bash
npm run preview
```

## Deploy

Anbefalt enkel deploy: Vercel eller Netlify.

Etter deploy kan domenet `lynell.no` peke fra Domeneshop til valgt host.
